01

Drei Arten von Sprachmodellen

Nicht jede KI schreibt Text

Gleiche Technik, verschiedene Aufgaben

Chat-Modell

schreibt

Bekommt Text, schreibt neuen Text. Wort für Wort.

z.B. ChatGPT, Claude, Qwen

Entscheidungsmodell

wählt

Bekommt Text, eine Frage und feste Antworten. Gibt eine Antwort und Wahrscheinlichkeiten zurück.

z.B. Nimble

Embedding-Modell

übersetzt in Zahlen

Bekommt Text oder ein Bild, gibt eine Liste von Zahlen zurück. Ähnliches bekommt ähnliche Zahlen.

z.B. EmbeddingGemma 2

"Das Derby war spannend,
in der 93. Minute …"

  Sport: 1.00, Politik: 0.00 }
[0.009, -0.060, 0.046,
 … 768 Zahlen]

Erfundene Beispielzahlen

Chat-Modell: wählt ein Wort, hängt es an, rechnet wieder. Hunderte Male, bis die Antwort fertig ist.
Entscheidungsmodell: rechnet einmal und schaut nur auf die Wahrscheinlichkeiten für unsere Antworten. Darum ist es schnell und kann nichts erfinden.
Vereinfacht. Wichtig ist die Idee: Im Innern eines Sprachmodells gibt es immer eine Wahrscheinlichkeitsverteilung. Ein Chat-Modell würfelt daraus Text, ein Entscheidungsmodell liest die Wahrscheinlichkeiten direkt ab.

Entscheidungsmodell

Nimble

  • Basiert auf Qwen3.5-9B, einem normalen Sprachmodell
  • Von Bespoke Labs nachtrainiert (fine-tuned) für Entscheidungen
  • Kein Nachdenken (kein «reasoning»), darum ca. 1 Sekunde pro Antwort
  • Wählt nur aus den Antworten, die wir vorgeben
  • Liest nur Text, keine Bilder

02

Embeddings

Bedeutung als Zahlen

Was ist ein Embedding?

Das Modell macht aus einem Text eine Liste von 768 Zahlen.

"Last-Minute-Sieg im Derby"
  ↓
[0.009, -0.060, 0.046, 0.016,
 -0.002, 0.029, -0.067, … 761 mehr]

Stell dir die Zahlen als Koordinaten auf einer Karte vor. Texte mit ähnlicher Bedeutung liegen nahe beieinander.

Die echte Karte hat 768 Richtungen statt 2.

Die Karte ist eine Illustration, keine echte Messung. Der Fussballclub-Artikel liegt zwischen Sport und Wirtschaft, darum sind sich die Modelle bei diesem Artikel uneinig.

Ähnlichkeit = Winkel zwischen zwei Pfeilen

KosinusBedeutung
1.0gleiche Richtung, gleiche Bedeutung
0.0haben nichts miteinander zu tun
In unserer Demo liegen alle Werte zwischen 0.55 und 0.72. Zwei deutsche Texte haben immer etwas gemeinsam. Nur die Reihenfolge zählt, nicht die Zahl selbst.

Darum gehen die Balken in der App vom tiefsten (leer) bis zum höchsten Wert (voll).

Kosinus-Ähnlichkeit: Skalarprodukt geteilt durch die Längen. Code steht in server/utils/ollama.js (cosineSimilarity), nur 10 Zeilen. Die Werte sind keine Prozente und ergeben zusammen nicht 1.

Kurze Hinweise sagen dem Modell, was es einbetten soll

1. Wir geben die möglichen Themen vor:

Ein Zeitungsartikel über Sport
Ein Zeitungsartikel über Politik
Ein Zeitungsartikel über Technologie

Davor kommt noch ein kurzer technischer Hinweis (Prefix), siehe nächste Slide.

2. Dazu kommt der Artikel:

title: none | text: Artikeltext …

3. Unser Code sucht das ähnlichste Thema: Sport.

Vorsprung des passendsten Themas gegenüber dem zweitbesten (Artikel «Last-Minute-Sieg im Derby»)

Englisch, ohne Prefix
0.019
Deutsch, ohne Prefix
0.044
Deutsch + Prefix
0.062
Eindeutiger heisst nicht automatisch richtig.
Prefixes aus der Modellbeschreibung: huggingface.co/google/embeddinggemma-2
Wir beantworten die Frage nicht selbst, wir geben die möglichen Antworten vor. EmbeddingGemma macht aus jeder Themenbeschreibung und aus dem Artikel Zahlen, unser Code sucht die ähnlichste. Das Prefix ist nur der technische Hinweis davor. Am meisten bringt es, in der Sprache des Artikels zu fragen (0.019 → 0.044). Das Prefix hilft zusätzlich (→ 0.062). Ein grösserer Vorsprung heisst nur: Das Modell ist sich eindeutiger. Ob die Zuordnung stimmt, ist eine andere Frage.

Was genau ans Modell geht

Ein Thema, so wie es ans Modell geht:

task: search result | query:
Ein Zeitungsartikel über Sport

Prefix: technischer Hinweis, immer gleich

Themenbeschreibung: schreiben wir selbst

Der Artikel, so wie er ans Modell geht:

title: none | text:
In der 93. Minute traf der Stürmer …

Prefix

Artikeltext

Deutsch oder Englisch?
Dafür gibt es keine Einstellung.
Es zählt nur, in welcher Sprache wir die Beschreibung schreiben:
«A news article about Sport» → Vorsprung 0.019
«Ein Zeitungsartikel über Sport» → Vorsprung 0.044
Das Prefix ist nur task: search result | query: bzw. title: none | text:. «Ein Zeitungsartikel über Sport» ist eine unserer vorgegebenen Antwortmöglichkeiten. Die Sprache ist keine Einstellung: Wir schreiben die Themenbeschreibung einfach auf Deutsch, weil der Artikel deutsch ist.

Lokal statt Cloud

  Vorteile

  • Datenschutz: Kamerabilder und Texte bleiben auf dem Laptop
  • Gratis: keine Kosten pro Anfrage
  • Offline: funktioniert ohne Internet
  • Kontrolle: das Modell ändert sich nicht über Nacht

  Nachteile

  • Hardware: Nimble braucht ca. 10 GB Arbeitsspeicher
  • Erster Start: das Laden dauert ca. 14 s
  • Kleinere Modelle: weniger können als die grossen Cloud-Modelle
  • Download: zusammen 10.6 GB

Ausprobieren und diskutieren

  Ausprobieren

  • Eigene Themen ins Themenfeld schreiben
  • Einen Text eingeben, der zu keinem Thema passt
  • Einen score-Typ einbauen: «Wie dringend ist diese News?»
  • Beschreibungen statt null: Umwelt: "Klima, Natur, Energie"
  • Farbnamen auf Deutsch: ändert sich etwas?

  Diskutieren

  • Ist «95 % sicher» dasselbe wie «stimmt zu 95 %»?
  • Wer ist schuld, wenn das Modell falsch sortiert?
  • Wo würdet ihr so ein Modell einsetzen, wo lieber nicht?
  • Brauchen wir für die Farbe überhaupt KI?
Letzte Frage ist bewusst provokativ: Der RGB-Wert ist ja schon die Farbe. Die KI gibt nur einen Namen und zeigt ihre Unsicherheit. Für viele Aufgaben reicht normaler Code.
